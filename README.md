# 인공지능 기초 실습실

### 👉 **[바로 열어 보기 — https://trmoo.github.io/aiBasics_trmoo/](https://trmoo.github.io/aiBasics_trmoo/)**

고등학교 2학년 **「인공지능 기초」** 학습지를 브라우저에서 **직접 조작해 보는** 웹앱입니다.

학습지가 「빈칸을 채우는 종이」라면, 이 앱은 그 빈칸의 값을 **직접 만들어 보는 실험실**입니다.
숫자를 바꾸면 그래프가 움직이고, 점을 끌면 상관계수가 바뀌고,
격자를 칠하면 합성곱 결과가 다시 계산됩니다.

- 🔌 **인터넷이 끊겨도 됩니다.** 외부 라이브러리를 하나도 쓰지 않았습니다.
- 🖥️ **파일 하나면 됩니다.** `dist/index.html` 을 더블클릭하면 열립니다.
- 🔒 **학생 개인정보를 수집하거나 저장하지 않습니다.**

---

## 학생용 — 이렇게 쓰세요

1. `index.html` 을 더블클릭해 엽니다.
2. 위쪽 **큰 탭**에서 단원을, 그 아래 **알약 단추**에서 학습지 꼭지를 고릅니다.
3. 파란 글씨의 **[보기]** 를 누르면 학습지의 괄호 정답이 열립니다. 먼저 스스로 채워 보세요.

## 선생님용 — 수업에서 쓰기

- 오른쪽 위 **[👁️ 정답 모두 보기]** 를 누르면 그 화면의 괄호 정답이 한꺼번에 열립니다.
  설명하실 때 쓰시고, 학생이 풀 때는 꺼 두세요.
- 주소창의 `#nn/cnn` 처럼 **화면마다 주소가 있습니다.** 특정 화면 링크를 학생에게 바로 줄 수 있습니다.
- 글자와 단추를 크게 잡아 두어 **전자칠판·교실 TV** 에서도 뒷자리까지 보입니다.

## 무엇이 들어 있나 — 탭 6개, 화면 23개

### Ⅰ. AI 구현 프로세스
문제 정의부터 성능 평가까지 여섯 단계 지도 · 정형/반정형/비정형 카드 나누기 ·
**기술 통계 실험실**(자료를 고치면 평균·분산·사분위수·상자그림이 실시간) ·
다섯 가지 그래프 갤러리 · **점을 끌면 상관계수가 바뀌는 산점도** · 상관 히트맵

### Ⅱ. 데이터 전처리
결측치 처리 5가지를 눌러 표가 바뀌는 것을 확인 · **IQR 이상치 탐지기**(점을 끌면 경계가 다시 계산) ·
정규화가 왜 필요한지 **거리 계산으로 증명** · 레이블/원핫 인코딩 변환기

### Ⅲ. 모델링과 평가
분류 vs 회귀 · **k-평균 군집화를 한 걸음씩** · 훈련:검증:평가 분할 · 교차검증 ·
**과적합 실험실**(차수를 올리면 두 오차가 갈라진다) · 혼동행렬 계산기 ·
**임계값을 옮기면 정밀도와 재현율이 반대로 움직이는 실험** · 정확도의 역설 ·
**MSE 를 정사각형 넓이로 그린 회귀 지표** · KNN · 의사결정트리

### Ⅳ. 신경망과 딥러닝
**퍼셉트론 실험실** — 슬라이더로 직선을 옮겨 AND·OR 은 되고 XOR 은 안 되는 것을 직접 확인 ·
다층 신경망이 두 직선으로 XOR 을 가르는 그림 · 활성화 함수 5종 · 소프트맥스 ·
경사하강법(학습률이 크면 발산) · **신경망이 XOR 을 스스로 배우는 3000회 기록** ·
**합성곱 연산기** — 8×8 격자를 칠하고 필터를 한 칸씩 굴려 특징맵을 만든다

### Ⅴ. 탐색
**강 건너기** — 직접 배에 태워 옮기고, 잘못 두면 잡아먹히고, 상태 공간 그래프에 지나온 길이 칠해진다 ·
하노이 타워 · **BFS·DFS 의 OPEN·CLOSED 리스트가 한 걸음씩 바뀌는 애니메이션** ·
균일 비용 탐색 · **8-퍼즐** 네 가지 탐색이 살펴본 상태 수 겨루기 ·
**A\* 길 찾기** — 벽을 그리고 f=g+h 를 칸마다 확인

### Ⅵ. 지식 표현·추론과 윤리
**규칙 기반 추론 엔진** — 사실을 고르면 규칙이 하나씩 발화해 동물을 알아낸다(규칙도 직접 추가) ·
전문가 시스템 · 윤리 쟁점 5가지 · **편향 실험실** ·
**모럴 머신 13상황** 을 고르고 나면 아홉 가지 축으로 우리 모둠의 성향을 그려 준다

## 설치와 실행

### 그냥 쓰기 (권장)
- **인터넷이 되는 교실** — [https://trmoo.github.io/aiBasics_trmoo/](https://trmoo.github.io/aiBasics_trmoo/) 로 들어가면 됩니다.
- **인터넷이 안 되는 교실** — 위 주소에서 페이지를 저장하거나(`Ctrl+S`),
  아래처럼 직접 빌드해 나온 `dist/index.html` **한 파일**을 USB로 옮겨 더블클릭하세요.
  설치도 인터넷도 필요 없습니다.

### 고쳐 쓰기
```bash
cd 22aiBasics_trmoo
npm install
npm start        # 개발 서버 — http://localhost:5174
```

```bash
npm run build    # dist/index.html 한 파일로 묶기
```

```bash
npm test         # 학습지 정답 98가지와 대조
```

## 알아 두실 것

- 학습지 **25쪽의 A~Z 도로 그래프**와 **30쪽 6×6 격자의 장애물 배치**는
  원본이 그림이라 값을 읽을 수 없었습니다. 같은 것을 가르치는 다른 자료로 대신했고,
  격자는 **눌러서 편집**할 수 있으니 원본대로 옮겨 쓰셔도 됩니다.
- 학습지 8쪽 표의 정밀도·재현율 설명이 서로 바뀌어 있습니다.
  앱은 9쪽 [활동 1]·[활동 3]의 채점 정답(표준 정의)을 따랐습니다. 자세한 사정은 `CLAUDE.md` 참고.
- **모럴 머신 활동은 정답을 고르는 문제가 아닙니다.** 토의를 시작하기 위한 장치입니다.
  앱 화면에도 그렇게 적어 두었습니다.
